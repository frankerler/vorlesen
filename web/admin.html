Vorgeschlagene Lesungen

Visitor-Vorschläge laufen über Formspree — dort siehst du jede Einreichung live (und bekommst sie per E-Mail), keine eigene Anmeldung für Besucher:innen nötig.

So übernimmst du einen Vorschlag in die Liste

  1. Prüfe neue Einreichungen im Formspree-Dashboard (oder in der Benachrichtigungs-E-Mail).
  2. Exportiere die Einreichungen, die du übernehmen willst, als CSV (Formspree: Form → Submissions → Export).
  3. Lege die CSV irgendwo lokal ab und führe aus: 
    .venv/bin/python scripts/import_formspree_submissions.py pfad/zur/submissions.csv --dry-run
.venv/bin/python scripts/import_formspree_submissions.py pfad/zur/submissions.csv
  4. Das Skript hängt neue Einträge an data/events.json/.csv an. Danach committen und pushen: 
    git add data/ && git commit -m "Add community-suggested reading(s)" && git push

Einreichungen, die du nicht willst, lässt du einfach in der CSV weg (Zeile löschen) oder markierst sie in Formspree als gelesen/archiviert — sie werden dann nicht importiert.
